# Performance Goals / OKR Tracking Plan

**Goal:** HR can set per-employee goals (optionally tied to a review cycle), track progress 0–100 and status, and employees can read their own goals.

## Schema
`migrations/20261204000001_performance_goals.sql`:
`performance_goals(id, tenant_id, employee_id, cycle_id NULL, title, description, target, progress, status, created_by, created_at, updated_at)`
- title 1–200; description ≤1000; target ≤200; progress 0–100; status in `active|achieved|cancelled`.
- `cycle_id` references `performance_cycles(id) ON DELETE SET NULL`.
- indexes `(tenant_id, employee_id, status)` and `(tenant_id, cycle_id)`; RLS forced + tenant policy.

## Service (`talentos-hr-runner/src/goals.rs`)
- `GoalInput` / `GoalView` (includes cycle name when linked).
- `list_goals(pool, tenant, employee_id, cycle_id: Option<Uuid>)`.
- `create_goal` — employee must belong to tenant; cycle must belong to tenant.
- `update_goal(goal_id, progress, status)` — validate 0–100/status.
- `delete_goal`.
- `list_my_goals(user)` — self, tenant scoped.
- `GoalError` → 404/422.

## Endpoints
- `GET/POST /api/v1/employees/:id/goals` (`employee.read_all` / `employee.update`) with optional `?cycle_id=`.
- `PATCH/DELETE /api/v1/goals/:id` (`employee.update`).
- `GET /api/v1/me/goals` (self).

## UI
- `/goals` (nav “เป้าหมาย”, HR writes; payroll read-only):
  - employee selector, optional cycle filter, add form (title/cycle/target/description);
  - goals table (`goal-row`) with progress input, status select, save (`save-goal`), delete.
- Shell: nav item + `hrOnly` guard.
- PDPA export: add goals per employee.

## Tests
- DB: create/list (with cycle filter), progress/status update + validation, delete, tenant + self scoping, cycle/employee cross-tenant rejected.
- E2E: HR adds a goal for E2E001, sets progress 40, saves, sees 40%; payroll can open read-only; employee redirected.
- Gates: fmt/clippy/tests/build, Playwright 52/52 (or final count).

## Out of scope
- No key-result sub-items, weights, alignment, check-ins/reminders, or employee self UI.
